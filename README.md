# Satashi Signal Map

Анимированная карта мира с узлами Satashi в Европе, визуальными линиями сигналов и эффектом «цифрового дождя». Это демонстрация интерфейса: точки и движения генерируются в браузере, данные о реальных сетевых событиях не загружаются.

## Запуск

Откройте `index.html` в современном браузере. Сборка, сервер и установка зависимостей не нужны.

## Файлы

- `index.html` — структура страницы и SVG-карта.
- `styles.css` — оформление и адаптивная раскладка.
- `app.js` — анимация узлов, линий и фонового эффекта.

Проект подходит как визуальный прототип и основа для дальнейшего подключения реального источника данных. Лицензия на повторное использование кода не указана.
